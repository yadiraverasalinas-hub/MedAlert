# MedAlert · Web de farmacia

## Abrir el proyecto

Abre `index.html` en la raíz del proyecto. Ese archivo redirige a `pages/index.html`, donde se encuentra la interfaz.

## Estructura

```text
assets/
  fonts/
  icons/
  images/
  videos/
css/
  styles.css
design/
  recursos exportados desde MedAlert.fig
docs/
  README.md
js/
  funciones.js
  main.js
  web-app.js
pages/
  index.html
MedAlert.fig
index.html
```

Los recursos exportados desde Figma se mantienen juntos en `design/` para conservar sus rutas. Los estilos y el código propio de la web están separados en `css/` y `js/`.

## Nota

La interfaz usa registros de ejemplo para la demostración académica. No consulta servicios oficiales ni envía reportes.
