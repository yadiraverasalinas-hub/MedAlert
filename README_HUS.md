## Historias por segmento

-   **Consumidores de medicamentos:** captura de evidencia, guía visual,
    extracción y corrección de datos, análisis del empaque, contraste
    con fuentes oficiales, alertas, clasificación de riesgo y
    recomendaciones.
-   **Adultos mayores y cuidadores:** verificación guiada y accesible,
    captura multicara, identificación de datos, comparación de
    productos, alertas de similitud, explicación simplificada y opciones
    de soporte.
-   **Personal de farmacia:** verificación rápida durante la recepción,
    checklist, extracción y contraste documental, inspección del
    empaque, consulta de alertas, clasificación de riesgo y gestión de
    productos observados.

## Alcance de este listado

Este README documenta las historias de usuario Must incluidas en la
tabla proporcionada para el proyecto. La presencia de una historia en
este listado no implica, por sí sola, que su funcionalidad ya esté
implementada; el estado de desarrollo y validación debe registrarse por
separado.
